# 豆瓣音乐收藏高级搜索（油猴脚本）

在豆瓣音乐 **个人「听过 / 想听 / 在听」页面** 右侧栏注入高级搜索面板，跨**全部收藏**按
**作品名 / 表演者 / 发行年份 / 标签 / 我的评分 / 标记日期** 精确检索——豆瓣官方收藏页只有按时间/评分/标题排序和单标签筛选，没有字段级搜索。

> 调研结论：Greasy Fork 与 GitHub 上**没有人做过**音乐收藏页的字段级页内搜索。最接近的「豆瓣观影/豆列-年代筛选」（greasyfork 556815）只做电影、只有年代、只作用于当前页；各类导出脚本（bambooooo 420999 等）能拿到全量字段但需导出后自己筛。本脚本把「全量抓取建索引」和「页面内即时检索」合并到一个油猴脚本里。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox / Safari 均可）；
2. 新建脚本，把 `douban-music-advanced-search.user.js` 全文粘贴进去保存；
3. 打开你的收藏页，例如 `https://music.douban.com/people/<你的ID>/collect`，右侧栏顶部会出现「高级搜索 · 听过」面板。

## 使用

1. 首次点 **建立 / 重建全量索引**：脚本以 1.5–2.6 秒/页的限速抓完全部收藏页（约 8–10 分钟 / 5000 条），进度实时显示；索引存在浏览器本地，按 `用户ID + 听过/想听` 分开存。
2. 之后搜索是毫秒级。索引超过 12 小时会自动后台增量更新（最多翻 8 页，遇到无新条目即停）。

### 检索维度

| 维度 | 说明 |
|---|---|
| 作品名 | 空格分隔多关键词 = 同时满足；大小写不敏感 |
| 表演者 | 子串匹配，如 `Coltrane` |
| 发行年份 | 起止闭区间，如 `1990`–`1999`；可勾选「包含年份未知」 |
| 标签 | 逗号/空格分隔，**精确匹配**；默认全部命中（AND），可切 OR；输入框有自动补全（从你的索引统计的标签） |
| 我的评分 | 最低–最高（★–★★★★★）；「最低」里可选「只看未评分」 |
| 标记日期 | 起止日期，原生日期选择器 |
| 组合 | 六维任意叠加 |

结果在侧栏面板列出：标题（点击跳条目页）、表演者·年份·评分·标记日期、标签 chips（点一下即加入筛选）；支持**导出 CSV**。

## 字段来源（实测）

脚本抓取 `?mode=list` 页面，每个条目 DOM 里就有：

- `.title a` → 作品名
- `.grid-date .intro` → `表演者 / 发行日期 / 类型 / 介质 / 风格`（脚本取第 1 段为表演者、从中提取 4 位年份）
- `.grid-date .tags` → `标签: ...`
- `.date` 内 `rating{N}-t` 的 class → 你的评分（1–5），其后文本 → 标记日期

> 注意：标签只在 list 模式渲染，grid 模式没有 `.tags`，所以抓取强制用 list 模式。部分条目 `.intro` 不完整（可能只有 `表演者 / 日期` 或缺失），年份会缺，按选择标注为「年份未知」、不联网补抓。

## 隐私与安全

- **数据不出本地**：索引存于 Tampermonkey 本地存储（`GM_setValue`），搜索全部在浏览器内完成。
- **外发请求仅限 `music.douban.com`**：`@connect music.douban.com` 锁死，仅抓取你自己的收藏页（登录态同源请求）；无任何第三方域名、无统计/埋点。
- **无凭据**：不需要 API Key / Token / Cookie 手动配置；脚本运行在已登录的豆瓣页面里，复用浏览器会话。
- **无硬编码身份**：用户 ID 与状态在运行时从 URL 派生，存储键随之生成，脚本里不含任何个人标识。
- 全部面向用户的 innerHTML 输出均经 `esc()` 转义，防注入。

## 已知限制

- 建索引期间不要关闭页面；中断不损坏已有索引，下次增量续上。
- 限速已压到很保守；若遇 403，脚本安全中断并提示，已抓部分保留。
- 豆瓣若改版收藏页 DOM 结构，`parseList` 的选择器需同步更新。

## 技术栈

纯原生 JavaScript，零依赖，`@grant` 仅用 `GM_xmlhttpRequest` / `GM_setValue` / `GM_getValue` / `GM_deleteValue` / `GM_addStyle`。
